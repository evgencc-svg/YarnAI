# Канон Yarn AI

## Действующий продуктовый канон

- Yarn AI — продаваемый личный технолог по вязанию.
- Первая коммерческая функция — адаптация существующей схемы.
- Исходный документ первичен.
- Исходные данные и пользовательская адаптация разделяются.
- Каждое число имеет происхождение: источник, подтверждённое решение или формула.
- Детерминированные расчёты выполняются кодом.
- Модель не придумывает недостающие данные или инструкции.
- Критические данные подтверждаются.
- Неопределённость показывается честно.
- Наталья проверяет продукт как реальная вязальщица.
- Цель — продаваемый продукт, а не бесконечное исследование.

## Сейчас не реализовывать

- расчёты и исполнимый план изделия по фотографии до принятия отдельного блока visual brief → technology options;
- диагноз ошибки по одному снимку;
- маркетплейс;
- социальную сеть;
- поддержку всех ремёсел;
- автоматическую поддержку всех конструкций вязания.

## Отдельная принятая программная граница

- `GARMENT PHOTO → TECHNOLOGY OPTIONS V1` разрешает только: reference photos → честное разделение наблюдений/предположений/неизвестного → вопросы → 1–3 собственные технологии YarnAI → сохранённое решение пользователя.
- Эта граница не восстанавливает оригинальную схему, не считает петли/ряды, не создаёт execution plan и не доказывает физически связанную вещь.
- Production provider остаётся выключенным до отдельного server-side разрешения и контролируемой приёмки.
