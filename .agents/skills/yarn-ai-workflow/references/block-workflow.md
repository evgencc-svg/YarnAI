# Работа одним блоком

Основной поток:

человеческий результат → граница → минимальная схема → проверка реализуемости → контракт блока → сквозной скелет → автоматические тесты → живой интерфейс → пользовательская приёмка → обновление состояния

## Контракт блока

Для каждого блока до реализации зафиксировать:

- вход;
- выход;
- ограничения и запреты;
- зависимости;
- критерий готовности;
- техническую проверку;
- пользовательскую проверку.

## Неизвестность

Каждой неизвестной части присвоить ровно один статус:

- `РЕАЛИЗУЕМО` — способ и проверка подтверждены;
- `НУЖНО КОРОТКОЕ ИСПЫТАНИЕ` — требуется минимальный опыт до архитектуры;
- `НЕ ДЕЛАЕМ` — часть вне границы или не имеет приемлемого способа реализации.

После пользовательской проверки остановиться. Следующий блок начинается только после явного решения Евгения.
