# ExecPlan — живой план Yarn AI

ExecPlan — обновляемый план сложной работы. Он обязателен для многошаговой функции, изменения нескольких частей системы, миграции данных, существенной неопределённости или работы, которая не помещается в одну задачу.

## Где хранить

- Активный план: `docs/plans/ACTIVE_<короткое-имя>.md`.
- Одновременно допускается ровно один `ACTIVE_*.md`, если Евгений явно не утвердил другое.
- Завершённый план перестаёт быть активным: переименовать его без префикса `ACTIVE_`, сохранив историю и итоговые доказательства.
- План не заменяет `PROJECT_STATE.md`: в состоянии проекта остаётся только подтверждённая текущая правда и один следующий шаг.

## Обязательная структура

```markdown
# <Название результата>

## Человеческий результат
## Граница
## Запреты
## Блоки
## Зависимости
## Проверка реализуемости
## Критерии готовности
## Технические проверки
## Пользовательская проверка
## Прогресс
## Решения
## Найденные ошибки
## Время и переделки
## Единственный следующий шаг
```

## Правила ведения

- Сначала фиксировать пользовательский результат, затем программные блоки.
- Для каждого блока указывать вход, выход, ограничения, критерий готовности и пользовательскую проверку.
- Не скрывать неизвестность: помечать её как `РЕАЛИЗУЕМО`, `НУЖНО КОРОТКОЕ ИСПЫТАНИЕ` или `НЕ ДЕЛАЕМ`.
- Обновлять прогресс и доказательства во время работы, а не восстанавливать их задним числом.
- Не начинать следующий блок до явного принятия предыдущего Евгением.
