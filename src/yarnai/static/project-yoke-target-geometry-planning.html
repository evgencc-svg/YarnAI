Когда должен начаться разрез поло относительно реглана?

Для варианта «после реглана» сначала рассчитывается закрытая кокетка. Передняя горловина, разрез и воротник остаются будущими отдельными этапами.

Какой должна быть готовая окружность верхнего края кокетки?

YarnAI не добавляет припуск и не принимает глубину горловины за окружность.

Какую часть верхнего края должен занимать каждый рукав?

Раздельный ритм корпуса и рукавов допускает несколько конечных распределений, поэтому нужен этот размер.
