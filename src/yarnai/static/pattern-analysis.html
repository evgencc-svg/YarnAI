Операции авторского размера

    Математический тест плотности 20 × 28

    Индивидуальный корпус

    Мерки тела, см
    Предлагаемые обхваты изделия, см
    Нижний край после стирки

    Свяжи по кругу резинку 1 × 1 (одна лицевая, одна изнаночная) из выбранной пряжи на спицах для низа. Выстирай и высуши образец так же, как свитер. Разложи без растяжения. В середине отсчитай петли и измерь ширину этого участка. Для высоты отсчитай круги и измерь их по вертикали.

    Мерки и выбор для полной инструкции

    Для версии с авторским верхом сверь горизонтальную плотность глади с исходной. Измерь выстиранные образцы своей пряжи. Расчёт использует одну плотность резинки на одинаковых спицах для горловины, низа и манжет.
