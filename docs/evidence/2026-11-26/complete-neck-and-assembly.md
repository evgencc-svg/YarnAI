# Anthony · цикл 4E · горловина и сборка

**PASS для авторской инструкции 52″ и 40″.** В каждом из двух новых проектов Edge проверены ряды корпуса и обоих рукавов, отделка, последовательность швов и итоговый контроль. После закрытия браузера и открытия из списка проектов совпали все развёрнутые операции и предупреждения. Сопряжение рукава с проймой остаётся **PARTIAL**. Оригинал проверен по локальным байтам и отдельно по тексту и чертежу страницы 3. [PDF издателя](https://cdn11.bigcommerce.com/s-x11gxbo1oj/content/berroco/patterns/Berroco_Anthony.pdf)

## От плеч до последней нити

| Участок | Действие для обоих размеров | Контроль |

| Четыре детали | Спинка, перед и два подписанных рукава завершены по выбранному столбцу. Соединить оба плеча | На спинке 41 живая петля, рабочие спицы и временный держатель переда пусты. Измерить плечи от горловины до проймы |

| Спинка | Провязать живые петли с её держателя. Поставить маркер и замкнуть круг | 59 + 41 = 100. Держатель пуст. Повторный перенос запрещён |
| Отделка | Каждый круг лицевыми до 2½″ (6,35 см). Свободно закрыть лицевыми | На спицах 0. Высота задаётся замером. Отдельной плотности отделки и обязательного числа кругов издатель не даёт |

| Продольные швы | Выполнить боковые швы корпуса и швы обоих рукавов | Совместить низ и подмышку, манжету и подмышку. Для каждого шва проверить длины обоих краёв |
| Завершение | Заправить концы нитей и по желанию обработать изделие | Итоговые наблюдения YarnAI — окружность груди и длина от плеча, общий снимок с лентой |

Для корпуса и рукавов применены соответственно пятый и второй из семи размерных столбцов. Числа горловины общие в оригинале. Механизм читает общие значения и размерные векторы. Получатель живых петель принимает остаток расчёта спинки и сверяет его с текстом отделки. Числа Anthony в расчёте не зашиты. В отдельном искусственном столбце 12 + 25 + 13 + 36 = 86. Внутри парных швов YarnAI показывает левую сторону первой. Издатель задаёт последовательность групп. Метки, намётка, измерения и 18 точек ручного журнала — технологические проверки YarnAI.

## Независимая геометрия

Для повторной проверки Python отдельно прочитал текст из исходного PDF, выбрал столбцы по окружности груди и построил ломаные в сантиметрах. Расчёты JavaScript в этой проверке не вызывались. Единицы лицевой глади — 20 п. и 27 р. на 4″. Одна петля по ширине равна 0,508 см, один ряд по высоте равен 10,16/27 см.

| Параметр | 52″ | 40″ |
| --- | ---: | ---: |
| Закрытие подмышки на каждом крае | 7 п. | 4 п. |
| Парных убавок проймы / оката | 8 / 29 | 4 / 27 |
| Верхняя ступень с каждой стороны / полное верхнее закрытие | 2 / 13 п. | 2 / 9 п. |
| Глубина проймы, текст и чертёж | 11″ = 27,94 см | 9½″ = 24,13 см |
| Высота оката по рядам / на чертеже | 62 р. = 23,33 см / 9¼″ = 23,50 см | 58 р. = 21,83 см / 8½″ = 21,59 см |
| Пройма от подмышки до плеча | 32,7392 см | 26,7836 см |
| Половина оката от подмышки до середины верха | 35,2069 см | 30,8509 см |
| Окат минус пройма, полный контур до округления | **+4,9353 см** | **+8,1346 см** |

От подмышки сначала учитываются горизонтальное закрытие и подъём двух рядов. На каждом склоне группа одиночных убавок имеет ширину по числу убавок и высоту по двум рядам на убавку. Прямой остаток проймы заканчивается на глубине плеча. На окате следуют диагональ верхней ступени за два ряда и половина верхнего горизонтального края. Последний ряд закрытия проходит поперёк. Его высота повторно не прибавляется. Две половины дают один полный верх. Для каждого рукава соединяются одна пройма переда и одна спинки. Расхождения с арифметикой 4D не обнаружено. Авторские ряды сохранены. Допуск по припосадке и физическая длина швов неизвестны.

## Испытания и восстановление

- Штатный `npm test` — код выхода 0, 2327 успешных исполнений, включая поло, контрольные точки и сохранение. Целевая группа Anthony — 93/93, из них 34 проверки сборки. Отрицательные случаи включают потерю держателя, повтор переноса, неверные спицы, направление и участки набора, сумму, высоту, размер, край, рукав, повтор шва, пропуск замера, преждевременное завершение, ошибку привязки фотографии и повреждение журнала. Проверены все префиксы журнала и независимый размер.
- Полный Python штатным интерпретатором Windows — 1643 прошли, 1 пропущен, 53,22 с. Первый запуск в изолированной среде не дал вывода и позднее был остановлен. Сборка и проверка изменений Git прошли. Тест разбора текста около миллиона символов занял 3,932 с внутри штатного набора и 2,872 с в отдельном прогоне файла (34/34). Прежний предел 5 с сохранён.
- Два проекта созданы через форму, импортирован оригинал и выбран размер. Без физических данных сохранена точка ожидания замера. Перезагрузка, полное закрытие процесса и повторное открытие по карточке дали тот же текст. Повторены независимые пооперационные проверки 4C/4D, проверены все 18 точек, остатки и предупреждения. Экспорт обеих карточек восстановил исходные байты PDF. Контрольные суммы развёрнутого экрана новых проектов — 52″ `07a632570b071feea64e80395d84f102ab8821691f9167f689c10a8835c2431e`, 40″ `82dec52e30e8d55f095264086c109c6505fea6df517db9ebc077e5273a74995a`.
- Четыре старые карточки проверены на копиях исходных хранилищ 4C и 4D, на прежних адресах. Каждая открыта из списка дважды в отдельных процессах. Без нового импорта появилась сборка, держатель и четыре детали сохранились. Развёрнутые экраны на каждом размере совпали между обеими версиями старых карточек. Повторный экспорт всех четырёх содержал первоначальный PDF.
- Отдельный искусственный проект в Edge сохранил восемь отмеченных операций, держатель 0, на круговых спицах 100, черновик высоты 4,3 см и тестовую картинку с надписью. Неправильные спицы 5 мм были отклонены. Новый процесс восстановил тот же текст и значение поля, файл картинки открылся из локальной записи. Ни одна из этих отметок не представляет реальное вязание. На двух основных карточках отмечено 0 из 18. Файл с изменёнными байтами и прежним текстом, а также PDF без страницы рукавов не дали исполнимой сборки.
- Поло в Edge — плотность производителя, отказ при недостающей плотности по рядам, расчёт, 36 шагов, возврат в сохранённую карточку. Barley Field в Chrome после перезапуска восстановил прежние 14 шагов с полным совпадением текста.
- Платные запросы YarnAI — **0**, стоимость **$0**. Прикрепление, просмотр снимка и сверка замеров выполняются локально. Пользователь отмечает результат после осмотра. При нехватке данных сохраняется точка ожидания замера или более информативного снимка. Автоматическое заключение о качестве шва по фотографии в этом маршруте отсутствует.
