# Планы Yarn AI

Правила ExecPlan находятся в `../../.agent/PLANS.md`.

Активная сложная работа хранится в одном файле `ACTIVE_<короткое-имя>.md`. После завершения префикс `ACTIVE_` убирается, а подтверждённый результат переносится в `../project-control/PROJECT_STATE.md`.

На момент завершения установки управляющей системы активного плана разработки продукта нет. Единственный следующий шаг указан в `../project-control/PROJECT_STATE.md`.
